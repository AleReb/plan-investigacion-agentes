# Prompt para revisión independiente

Lee AGENTS.md, la tarea y sus criterios. Contrasta la entrega con las fuentes fijadas. Comprueba cada afirmación sustantiva, localizadores, versiones, autoría, límites y separación entre observado/declarado/inferencia. Verifica que las pruebas mencionadas existan y que no se haya dado por validado hardware sin ensayos.

Entrega resultados/<ID>/revision.md con decisión recomendada aceptar/devolver/bloquear, evidencia revisada, errores concretos y corrección mínima necesaria. No reescribas silenciosamente la entrega ni cambies el backlog. Si el protocolo científico es insuficiente, escala al coordinador. El coordinador registra la aceptación final.
